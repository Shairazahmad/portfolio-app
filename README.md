# Personal Portfolio & Admin Panel 🚀

A modern, full-stack personal portfolio website built using the MERN stack (MongoDB, Express, React, Node.js) and Vite. Features a responsive frontend UI and a custom CMS/admin dashboard for managing projects and content dynamically.

## ✨ Features

- 📱 **Fully Responsive:** Mobile-first layout styled with Tailwind CSS.
- ⚡ **Fast Performance:** Built with React + Vite for quick page loads.
- 🛠️ **Custom Admin Panel:** Easily manage, add, or edit portfolio projects.
- 📧 **Direct Contact:** Quick links for GitHub, LinkedIn, Fiverr, and Gmail outreach.

## 🛠️ Tech Stack

- **Frontend:** React, React Router, Tailwind CSS, Lucide Icons, Vite
- **Backend:** Node.js, Express.js
- **Database:** MongoDB Atlas (Mongoose)
- **Authentication:** JSON Web Tokens (JWT)
